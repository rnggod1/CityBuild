# CityBuild - Градостроительный симулятор

2D градостроительный симулятор на Python с использованием Pygame. Игрок строит и развивает город, управляет населением и добывает ресурсы.

## 🎮 Возможности

### 🏗️ Строительство
- **7 типов зданий**: дом, ферма, склад, лесопилка, каменоломня, рынок, ратуша
- **Множественное строительство**: выберите здание и стройте несколько раз подряд
- **Ограничения**: максимум 1 ратуша и 2 склада
- **Предпросмотр размещения**: зелёная/красная подсветка при строительстве

### 🌍 Генерация мира
- **3 размера карты**: 64x64, 128x128, 256x256
- **Случайная генерация**: озёра, реки, горы, леса, плодородные земли
- **Текстуры** для разных типов местности

### 📊 Экономика
- **Ресурсы**: дерево, камень, еда, золото, население
- **Производство**: фермы производят еду, рынки - золото
- **Потребление**: население потребляет 0.05 еды за 30 секунд на жителя
- **Баланс**: ферма производит 2 еды за 30 секунд

### 🎯 Управление
- **WASD/стрелки** - перемещение камеры
- **Колесо мыши** - зум
- **B** - открыть/закрыть панель построек
- **1-7** - быстрое выбор здания
- **ЛКМ** - разместить здание/выбрать объект
- **ПКМ** - отменить выбор
- **Space** - пауза
- **Esc** - главное меню


### Требования
- Python 3.8+
- pygame-ce 2.5.8+
